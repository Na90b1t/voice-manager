**Нет!** Для второго способа (**автозагрузка через `.vbs`**) **не нужно скачивать NSSM или любые другие утилиты**.

NSSM нужен **только для создания службы Windows** (первый способ).  
А **второй способ — полностью встроенный в Windows**, использует только:

- **Папку автозагрузки** (встроенная функция Windows)
- **Файл `.vbs`** (скрипт на языке VBScript, который поддерживается Windows по умолчанию)

---

## ✅ Что нужно для второго способа (автозагрузка без окна):

1. **Ваш проект** в папке, например: `C:\TimeManager`
2. **Python установлен** и доступен из командной строки (проверяется командой `python --version`)
3. **Файл `VoiceManager.vbs`** — создаёте **сами в Блокноте**, без скачиваний

---

## 📝 Как создать `VoiceManager.vbs` (пошагово)

1. Нажмите **Win + R** → введите `shell:startup` → Enter  
   → Откроется папка автозагрузки (обычно `C:\Users\ВАШ_ПОЛЬЗОВАТЕЛЬ\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`)

2. Кликните правой кнопкой → **Создать → Текстовый документ**

3. Вставьте этот текст:
   ```vbscript
   CreateObject("Wscript.Shell").Run "python C:\TimeManager\manager.py", 0, False
   ```

4. Сохраните файл как **`VoiceManager.vbs`**  
   → **Важно**: расширение должно быть `.vbs`, а не `.txt`  
   → Если не видите расширений: в Проводнике → Вид → Поставьте галочку «Расширения имён файлов»

---

## 🔍 Как это работает?

- При входе в систему Windows **автоматически запускает все файлы** из папки автозагрузки
- `.vbs` — это скрипт, который:
  - Запускает `python C:\TimeManager\manager.py`
  - Параметр `0` — **скрывает окно консоли**
  - `False` — не ждёт завершения (работает в фоне)

→ Никаких внешних программ не нужно — только то, что уже есть в Windows.

## ✅ Проверка

1. Перезагрузите компьютер
2. После входа в систему:
   - Откройте **Диспетчер задач** → вкладка «Процессы»
   - Найдите `python.exe` — он должен быть запущен
3. Дождитесь ближайшего времени из `schedule.json` — должен прозвучать голос

## 💡 Совет: если Python не найден

Если скрипт не запускается, укажите **полный путь к python.exe**:

```vbscript
CreateObject("Wscript.Shell").Run """C:\Python39\python.exe"" ""C:\TimeManager\manager.py""", 0, False
```

> Узнать путь к Python:  
> Откройте CMD → введите `where python`
