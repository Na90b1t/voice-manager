## 📄 1. `piper_wrapper.py` — надёжная озвучка

```python
import subprocess
import os
import tempfile
from pathlib import Path

# === НАСТРОЙКИ ===
PIPER_DIR = "piper"                     # папка с piper.exe
MODEL_NAME = "ru_RU-irina-medium.onnx"  # имя вашей модели
# =================

def speak(text):
    if not text or not text.strip():
        return

    piper_path = os.path.join(PIPER_DIR, "piper.exe")
    model_path = os.path.join(PIPER_DIR, MODEL_NAME)

    # Проверка файлов
    if not os.path.exists(piper_path):
        print(f"❌ Не найден piper.exe: {piper_path}")
        return
    if not os.path.exists(model_path):
        print(f"❌ Не найдена модель: {model_path}")
        return

    # Создаём временный WAV
    with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as tmp:
        tmp_path = tmp.name

    try:
        # Генерация аудио в файл
        cmd = [piper_path, "--model", model_path, "-f", tmp_path]
        result = subprocess.run(
            cmd,
            input=text.strip() + "\n",
            text=True,
            encoding='utf-8',
            capture_output=True
        )
        if result.returncode != 0:
            print(f"Ошибка Piper: {result.stderr}")
            return

        # Проигрываем через PowerShell (встроено в Windows)
        play_cmd = [
            "powershell", "-c",
            f"(New-Object Media.SoundPlayer '{tmp_path}').PlaySync()"
        ]
        subprocess.run(play_cmd, check=True)

    finally:
        # Удаляем временный файл
        try:
            Path(tmp_path).unlink(missing_ok=True)
        except Exception:
            pass
```

## 📄 3. `manager.py` — основной цикл

```python
import json
import time
import datetime
from piper_wrapper import speak

def load_schedule():
    try:
        with open("schedule.json", "r", encoding="utf-8") as f:
            return json.load(f)
    except Exception as e:
        print(f"Ошибка загрузки расписания: {e}")
        return {}

def get_current_schedule(schedule):
    weekday = datetime.datetime.now().weekday()  # 0=Пн, 6=Вс
    return schedule.get("weekdays" if weekday < 5 else "weekend", {})

def main():
    print("✅ Голосовой менеджер запущен. Проверка каждую минуту...")
    last_triggered = set()

    while True:
        now = datetime.datetime.now()
        current_time = now.strftime("%H:%M")

        schedule = load_schedule()
        today_schedule = get_current_schedule(schedule)

        if current_time in today_schedule and current_time not in last_triggered:
            message = today_schedule[current_time]
            print(f"📢 [{current_time}] {message}")
            speak(message)
            last_triggered.add(current_time)

        # Сброс в полночь
        if current_time == "00:01":
            last_triggered.clear()

        time.sleep(60)  # ждём 1 минуту

if __name__ == "__main__":
    main()
```

@echo off

## 📌 Как установить

1. **Создайте папку**, например: `C:\TimeManager`
2. **Скопируйте в неё** все 4 файла выше
3. **Поместите папку `piper`** (с `piper.exe`, моделью и `espeak-ng-data`) в `C:\TimeManager\`
4. **Проверьте модель**:  
   - Имя в `piper_wrapper.py` (`MODEL_NAME`) должно совпадать с файлом
   - Пример: `ru_RU-irina-medium.onnx`
5. **Запустите `start.bat`**

---

## 🔄 Как обновлять задачи

Просто откройте `schedule.json` в Блокноте и измените текст.  
Скрипт **автоматически подгрузит изменения** при следующей проверке времени.

---

## 🚀 Автозапуск при старте Windows

1. Нажмите **Win + R** → введите `shell:startup` → Enter
2. Создайте **ярлык** на `start.bat` в открывшейся папке
3. Перезагрузите ПК — менеджер запустится автоматически

---

## ❓ Если что-то не работает

- Убедитесь, что **`espeak-ng-data` есть в папке `piper`**
- Проверьте, что **модель называется точно так же**, как в `MODEL_NAME`
- Запустите `start.bat` **от администратора** (на всякий случай)
- Временно добавьте в `schedule.json` **текущее время** для быстрой проверки
